\begin{abstract}
Sources often date historical changes only to a month or year.
Choosing an exact date can change the evidence retrieved for a question.
We ask when resolving these dates can change the selected evidence.
Our method represents each stated change by a date range and records which claims can replace others.
At most two source events, called witnesses, summarize each claim when event dates vary independently.
These witnesses identify evidence that could apply and evidence that must apply within a requested period.
An exact test then certifies an unchanged context or returns two valid timelines with different selected claims.
The test compares two filtered versions of a fixed ranking, without computing every attainable context.
The same criterion supports known event order and different query meanings through an exact constraint solver.
On 3,178 TimeQA questions, the automatic adapter reaches 309 contexts containing modeled evidence.
It certifies 245 as stable and verifies changes for the remaining 64.
Replacement changes 34 of 73 contexts in a separate source-derived challenge.
On controlled dependent dates, screening removes 59.79\% of the claim checks made by an otherwise identical solver.
The resulting interface identifies the source dates that can change a reader's evidence.
\end{abstract}
