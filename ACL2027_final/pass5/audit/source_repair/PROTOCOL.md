The reconstruction uses no QA labels, reader answers, or retrieval results.
The adapter freeze precedes full extraction and fresh source assessment.
The freeze includes all extraction helpers.

The calibration register contains 136 source articles.
It combines previous calibration articles with completed pass-4 source reviews.
It does not claim to enumerate all historical exposure.
The fresh audit separately excludes broader documented exposure.

The tests check pronouns, abbreviations, date ownership, endpoints, and bounded states.
The known-case checks cover all eleven omitted terminations in the preserved repair plan.
All source spans must match literal text.
The retrieval partition must preserve every source word.
Every replacement pair must retain both endpoints.

The adapter remains fixed after this freeze.
